# AIC 网站 UI / UX 优化交付

已在本地实现。未由本任务部署、推送或提交代码。

## A. 改善内容
保留四大支柱与原有业务内容。优化核心页面和共享组件，更新 Innovation Night。首页按用户最新指示保留原有 Sora 字体、居中 Hero、深蓝玻璃面板、大楼滚动视频与 ALEBEX 3D 球体。

## B. 视觉系统
内页采用海军蓝、白底、克制蓝色强调、Georgia 标题与清晰正文；统一间距、细边框、按钮层级和卡片。首页使用独立 home-polish.css，避免内页风格覆盖首页。

## C. UX
导航目的地与子菜单展开按钮分离；支持 Enter、Escape、焦点离开及外部点击关闭。核心页面增加页内导航。首页六步生态路径清晰呈现；移动端改为纵向连接线。

## D. 新组件
生态旅程、逐级选择的 Founders Lab 路径、Lab 基础设施层级、官方精选活动、核心页内导航、社区活动入口。Accelerator 中 Out of Box 以大面积深蓝案例版面突出，保留既有故事。

## E. 图片
未生成 AI 图片，未制作虚构产品截图。活动使用 Luma 官方封面，本地 800px 与 400px WebP，完整比例，不裁切文字。现有活动照片保留。

## F. 图标
四大支柱使用统一 24 单位 viewBox 的简洁线形 SVG，统一线宽和尺寸；保留品牌标识。

## G. 手机
核心页面检查 1440、1280、1024、768、430、390px；实际视口值已核对。已检查公开内容页面的 390px 版本。菜单、活动封面、路径与按钮没有观察到横向溢出。

## H. 可访问性
可见焦点、跳至正文、子菜单 aria-expanded / aria-controls、活动替代文字和日期语义、原生 FAQ、减少动态偏好支持。内页内容默认可见，避免滚动动画隐藏正文。未进行正式 WCAG 合规认证或屏幕阅读器全流程审核。

## I. 性能
保留原视频文件（约 5.96 MB），仅优化播放调度：停止滚动后停止无用动画循环，视频正在跳帧时避免重复 seek，后台暂停，避免视频已就绪后重新启动粒子层。实测视频从 0 推进到约 3.17 秒。新增样式约 32 KB 未压缩；未新增框架依赖。活动图片按屏宽选择并延迟加载。没有宣称 Lighthouse 或实际速度提升分数。

## J. 边界与后续
Out of Box 缺少提供的官方产品视觉及详细案例证据，故仅使用现有文字。历史五楼互动导览和按钮样式样本保持原体验。联系表单未发送真实提交。原视频在首次访问时仍有下载成本，未重新压缩或更换。修改前截图中的部分内容受原滚动 reveal 影响，不能视为内容缺失。
